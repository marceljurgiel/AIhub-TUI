# Shipping and returns

- Orders placed before 14:00 ship the same day from the Lisbon warehouse.
- Shipping is free in Portugal on orders over 40 EUR; otherwise it costs 4.90 EUR.
- Customers can return an item within 30 days. They pay the return postage,
  unless the item arrived faulty.
- Refunds go back to the original payment method within 5 working days.
